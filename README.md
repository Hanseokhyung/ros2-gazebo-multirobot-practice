# ROS2 Gazebo Multi-Robot Practice

ROS 2 Jazzy와 Gazebo를 이용한 개인 Multi-Robot 실습 프로젝트.

## Goal

TurtleBot4 2대를 Gazebo에서 운용하여 다음 과정을 직접 구현한다.

- Two Robot Spawn
- One RViz / Two Robots
- Multi-Robot TF / Namespace
- Automatic SLAM
- Map Merge
- Merged Map Save
- AMCL + Nav2
- Multi-Robot Patrol
- Gazebo Object Detection
- YOLO Integration

## Environment

- Ubuntu 24.04
- ROS 2 Jazzy
- Gazebo Harmonic
- RViz2
- TurtleBot4
- slam_toolbox
- multirobot_map_merge
- Nav2
- YOLO
